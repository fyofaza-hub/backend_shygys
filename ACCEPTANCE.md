## Как воспроизвести

Для приёмки поднимите тестовые PostgreSQL/PostGIS и Redis, задайте `DATABASE_URL` и `REDIS_URL`.

```bash
uv sync --locked
uv run alembic upgrade head
SHYGYS_INTEGRATION=1 uv run python -m pytest -q
```

Для нагрузки создайте отдельную пустую БД `shygys_load`, доступную только тестовому экземпляру API. На ней примените миграции и запустите Uvicorn на порту 58081. В другом терминале с тем же `DATABASE_URL` выполните следующую команду.

```bash
uv run python -m scripts.load_catalog --concurrency 40 --requests 4000
```

Повторный запуск требует новой пустой БД. Скрипт прерывается при ошибке ответа или превышении порога p95 каталогом.

## Проверки перед эксплуатацией

Нужны исходный XLSX с 43 ОКЭД и утверждённые геоданные ВКО. SMTP, S3, ClamAV, Browserless и AlemAI нужно прогнать на подключённых сервисах с конфигурацией заказчика. После выбора хостинга требуется проверить восстановление на отдельном стенде и согласовать сроки хранения, RPO/RTO и порядок окончательного удаления персональных данных.

## Проверка подключённых сервисов

На работающем API выполнен `python -m scripts.check_real_services --require-browserless` с реальными MinIO, контейнером Mailpit и внешним Browserless `production-sfo.browserless.io`.

- Оригинал JPEG 1400×1000 сохранён без изменений; хеш и байты прочитанного объекта совпали с загруженными.
- Воркер создал WebP 320×229 и 960×686. Анонимный HTTP GET оригинала в MinIO вернул отказ, API также требует авторизацию владельца.
- Mailpit получил письмо подтверждения, ссылка активировала аккаунт. Письма о решениях модерации получены через SMTP, дополнительно проверены темы и доставка на kk/ru/en.
- Экспорт дашборда через API вернул реальный PDF размером 20 468 байт и PNG размером 33 625 байт. Проверены сигнатуры и декодирование изображения.
- ClamAV не запускался согласно настройке тестового стенда `ENABLE_CLAMAV=false`. Проверены пропуск соединения при отключении и отказ при отсутствии конфигурации включённого сканера.

При первом реальном чтении S3 найден и исправлен дефект потока ответа. Контекстный менеджер `StreamingBody` возвращал объект `HTTPResponse`, у которого отсутствует `iter_chunks`. Теперь итерация выполняется по `StreamingBody` с гарантированным закрытием. Регрессионный тест использует настоящий класс botocore.

MinIO собран из официального исходного кода. Для Mailpit использован официальный образ `ghcr.io/axllent/mailpit:v1.27.4` в Podman без root, поскольку доступ к системному Docker socket закрыт. Состояние сервисов хранится в пользовательском каталоге `~/.local/share/shygys-services`.

После подключения сервисов и исправления S3-потока на чистой PostgreSQL/PostGIS базе прошли 24 теста. Ruff и проверка форматирования также прошли.
